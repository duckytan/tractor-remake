# 拖拉机大赛 · 网页重制版

把 1999 年的 Windows 游戏《拖拉机大赛 Ver 1.1》重制为可在现代浏览器运行的版本。

**重制的唯一动机**：原版是 632×450 定死的低分辨率窗口，在 2K 显示器上牌面看不清、
无法缩放、强行拉大只多出白边。规则本身是好的，坏的是渲染层。

**因此本项目的定位是：规则 1:1 复刻 + 渲染层完全重做。**

## 快速开始

```bash
npm install
npm run dev       # http://localhost:5173
npm test          # 单元测试 + 集成测试
npm run build     # 产出 dist/
```

> 依赖只有 4 个开发期包（typescript / vite / vitest / coverage-v8），**运行时依赖 0 个**。
> 装包慢时用 `npm install --registry=https://registry.npmmirror.com`。

**看素材效果**：直接双击 `design/preview.html`。

## 玩法与操作

| 操作 | 方式 |
|---|---|
| 选牌 | 点击手牌 / Tab 聚焦后按回车 |
| 出牌 | 点「出牌」或按 **空格** |
| 取消选择 | 点「取消」或按 **Esc** |
| 提示一手合法牌 | 点「提示」或按 **H**（只高亮，不改选择） |
| 亮主 | 弹层里选 4 花色 + 无将 |
| 扣底 | 庄家选满 8 张后点「扣底」 |
| 规则与体验设置 | 顶栏「设置」 |
| 对局记录 | 顶栏「记录」 |

**规则要点**（完整版见 `docs/rules/游戏规则规格书.md`）：

- 4 家各 25 张 + 8 张底牌，庄家收底牌后扣回 8 张
- 出牌分**首出**（同花色）与**跟牌**（张数一致、该跟的必须跟够）
- 甩牌逐组逐对比较，失败时裁剪为该组的**最小单位**
- 分数牌 5 / 10 / K，两副牌共 200 分；闲家先到 80 分升级
- 升级时**必打**级牌不能跳过（与出牌无关，是升级限制）

## 三条核心原则

1. **规则引擎与渲染层彻底分离。** 规则层不知道"牌画在哪"，渲染层不知道"什么是拖拉机"。
2. **不照抄原版的数据结构。** 逆向出来的 `handInfo` 五槽十组是 1999 年的性能优化，
   现代重写用语义化模型（对子数 / 单张数 / 代表牌）即可。
3. **每个规则都能被单测。** 规格书里的每条 `【确证】` 都应有一条对应断言。

## 与原版的关系

| 项 | 处理 |
|---|---|
| 游戏规则 | **1:1 复刻**（`【确证】` 项） |
| 原版缺失的规则（埋底、扣底翻倍、终局） | **补上**，见 ADR-006 / ADR-011 |
| 与原版不一致的细节（甩牌失败、必打） | **按标准规则修正**，见 ADR-008 |
| 视觉 / 布局 / 交互 | **完全重做** |
| 原版位图素材 | 不直接使用，牌面矢量重绘（ADR-003） |
| 原版 AI | 不移植，重写（ADR-012） |
