## 1. 移植清单

| # | 移植项 | 原文位置 | 为什么值得搬 |
|---|---|---|---|
| 1 | **钢琴 7 层泛音表** `PIANO_PARTIALS` | `engine-ab.html:672` | 我们原来只有 4 层，听感单薄发"电子"。7 层 + 每层独立衰减倍率，才有"高音先走、低音拖着"的真钢琴尾音 |
| 2 | **`playPiano` 的 `soft` 开关** | `:677` | `br<0.8` 时直接砍掉最高几层泛音 —— 同一个音色能出"亮/暗"两种性格，不用换音色 |
| 3 | **`phraseAccent()` 确定性力度呼吸** | `:418` | 我们原来用 `Math.random()`，听感是"散"。按「强拍重·弱拍轻·反拍再轻·句尾收·越高越亮」算出来才是"呼吸" |
| 4 | **`makeRng()` 确定性伪随机** | `:288` | 同一个小节每次生成的微抖动完全一致 ⇒ 可复现，不会越听越乱 |

| 6 | **音色闸门 `tone`（8.5kHz 低通）** | `:555` | 一处低通干掉所有音色的高频毛刺，比在每个音色里各加一次省事 |
| 7 | **压缩器参数** | `:557` | `-20dB / knee 22 / ratio 2.6 / attack 12ms / release 280ms`，比我们原来的更松，不会"压扁" |
| 8 | **左手和弦层** | `:1921` | 根音 + 五音的长音铺厚度 —— 我们原来完全没有这一层，织体是"飘"的 |
| 9 | **和声床两个音** | `:1931` | `p[0]+12` 与 `p[2]` 各一个，比我们原来单音垫底宽 |
| 10 | **`dens` 当密度用** | `:1901` | `(dens-0.75)*0.34` 作为加花**概率**，不是当音量阈值用 |
| 11 | **`playEPiano`（FM 电钢琴）** | `:826` | 正弦载波 + 2× 调制器，调制指数 0.32s 内从 `f*0.85` 塌到 `f*0.04`。**深度必须 < f**，否则瞬时频率穿过 0 变负（频谱折叠，听感发浊） |
| 12 | **`playFlute`（长笛）** | `:714` | 奇次谐波偏重 + 窄带气声 + 起音后渐入的抖音。气声中心频率跟着音高走（`2300 + f*0.4`） |
| 13 | **`playGuitar` 的两处琴身峰值** | `:657` | 128Hz 给厚度、420Hz 给木头的"膛" —— 拨弦音色"像木头"全靠这两个 peaking |
| 14 | **和弦表用绝对音高 6 声部** | `:443` | `p[0..5]` 从低到高排好。**旋律因此能用完整 C 大调音阶（含 F、B）**，不必锁在五声里 |

## 1b. 四季主题与播放引擎（v10，完整移植）

用户第二次指示：「将原本春夏秋冬四个主题也移植过去，包括播放引擎也移植过去」。

### 四季主题（`THEMES`，整条移植）

四条旋律都是参考实现作者自己的作品（同一项目的 `design/` 目录），
按用户要求连同演奏意图注释一起搬过来。四条都在 **C 大调、8 小节**，所以和声床不用跟着转调。

| 主题 | 主奏 | 音符数 | 音域 | 动机 |
|---|---|---|---|---|
| 春 · 萌动 | 长笛 | 37 | G4–A5 | 低音起跳（纯四度）→ 三连级进上行 → 落长音（"破土—抽芽—舒展"） |
| 夏 · 灼日 | 钢琴+吉他 | 44 | B4–A5 | 同音反复（蝉声）→ 冲刺上行 → 高音砸下 |
| **秋 · 落叶**（默认） | 钢琴 | 28 | E4–G5 | 三度下行"叹息"，前半句落下、后半句留白 |
| 冬 · 静雪 | 长笛+钢琴 | 26 | B4–C6 | 高音单点（雪落到钟上）→ 五度大跳下行 → 长空 |

默认「秋 · 落叶」：叹息动机 + 音区最低 + 长音最多，最贴 §3.0 的「慵懒午后牌桌」。

### 情绪预设（`MOODS`，8 个，整条移植）

`cafe / sunny / walk / memory / rain / dusk / tension / men`，
每个是一组 `{bpm, tp, gtr, pno, mel, dens, verb, bright, shaker, pad}`。

游戏三阶段各映射一种"光线"：

| 游戏场景 | 情绪预设 | 速度 | 性格 |
|---|---|---|---|
| 定主 · 埋底 · 回放 | `cafe` 咖啡小憩 | 66 BPM | 钢琴为主 · 慵懒 |
| 出牌（平稳） | `sunny` 午后阳光 | 72 BPM | 吉他+钢琴 · 基准 |
| 结算 · 终局 | `walk` 微风散步 | 80 BPM | 加沙锤 · 轻快 |

### 播放引擎（`scheduleBar` 按参考实现重写）

| 机制 | 说明 |
|---|---|
| `loopBar = bi % theme().loopBars` | 主题自身 8 小节一轮；和弦 `ci = loopBar % 4` |
| **变奏周期 `VAR_PERIOD = 8`** | 固定 8 小节，**不跟着循环长度走**。第一遍纯主题、第二遍加装饰（A A′），之后回纯主题 |
| `varFlags` 四种变奏 | 八度叠音（低 12 度 ×0.28）/ 下行四度对位（×0.20，隔音一次）/ 装饰音（提前 0.22 拍、低二度 ×0.32）/ 尾句加花（第 4 小节后三拍半插三个上行音） |
| `phraseAccent()` | 力度按拍位和音高算，不随机 |
| `makeRng(seed*31 + bi*7717)` | 每小节的微抖动确定性可复现 |
| 左手和弦 | 根音 + 五音长音（`beat*1.6`），`dens>0.7` 且 `ci` 为奇数时补三音 |
| 和声床 | `p[0]+12` 与 `p[2]` 两个音，`pad*0.10` / `pad*0.07` |
| `dens` 用法 | `(dens-0.75)*0.34` 作为加花**概率**，不是音量阈值 |

> **`VAR_PERIOD` 为什么固定 8 小节**：若让它跟着循环长度走（4 小节换一次变奏），
> 等于每十几秒换一副面孔，反而听不出主题是什么，上头感被冲掉。
> 8 小节主题 + 8 小节变奏周期 = 既有稳定的预测感，又不是每遍一样。

### 音色库扩充（12 种）

`原声钢琴 / 柔钢琴 / 电钢琴 / 钢片琴 / 八音盒 / 颤音琴 / 钢弦吉他 / 竖琴 / 长笛 / 马林巴`
+ 叠加 `钢琴+吉他 / 长笛+钢琴`。

新增 `addPartial()` 辅助（正弦 + 线性起音 + 指数衰减），钢片琴/八音盒/颤音琴/竖琴都用它。
八音盒的梳齿泛音比 **1 : 3.01 : 5.42 : 8.93**（非谐），颤音琴是 1 : 4 + 4.6Hz 振幅摆动（±16%）。

## 2. 主旋律（原创）

画面：「慵懒的下午，一群人在一起打牌」。8 小节 29 个音，音域 E4–E5。

写法上借鉴参考实现的**结构手法**（不是音符）：

| 手法 | 参考实现 | 我们的落地 |
|---|---|---|
| 有动机、隔小节再现 | spring 的 ①⑦ 节奏骨架逐拍相同 | 第 1、3 小节同一个「叹息」动机（下行级进 + 长音），第 3 小节整体移低 |
| 每小节节奏都不同 | autumn 八小节八种节奏 | 1/.5/1.5/.5 → 1/1.5/.5/1 → 2/2 → 1.5/.5/1/1 → … |
| 稳定句与色彩句交替 | 强拍落和弦音 | 第 2、4、6、8 小节全落和弦音；第 1、3、5、7 小节带 9 音/大七度/6 音 |
| 只有一次高点 | autumn 第 5 小节唯一 E5 | 第 5 小节 E5，全曲最高，只出现一次 |
| 沉到最低音 | autumn 第 7 小节 E4 | 第 7 小节 E4，叹气叹到底 |
| 半终止收尾、无缝循环 | autumn 停在导音 B4 | 第 8 小节停在 B4 两拍，接回第 1 小节 |

**和声校验**（纸面，`.tmp/` 下同）：29 个音里 20 个是和弦音、9 个色彩音，
**只有 1 处大七度**（第 5 小节 B4 对 C 和弦）—— 这是故意的留音，
下一小节立刻半音上行到 C5 解决，慵懒调子需要这个颜色。

**隔离实测**（清空伴奏网格后只留旋律，钩 `createOscillator` 记频率）：
出现的音级 `A×24 F×12 E×9 D×9 C×9 G×6`，**没有任何升降号**，控制台零错误。

## 3. 伴奏与编排

- **网格音型保留我们试听定稿的那一条**：低音在第 1 拍、第 2 拍后半、第 3 拍；
  五音+高三叠在第 2 / 4 拍。读作「咚 · 嗒 咚 咚 · 嗒」。
- **高三行整体再 +12**：马林巴是正弦泛音，八度一高，4×/9× 次泛音就落进
  3.5–5 kHz 的"空气"频段 —— 这是最便宜的补高频手段。
- **`bassMul`**：低音行按曲风单独缩放。慵懒要慢要松，低频太厚就变「沉」。
- **循环编排 8 小节一段 × 6 段 = 48 小节**：
  起 → 全奏 → 全奏 → 呼吸(抽旋律) → 转调+2 → 收尾。
  旋律从头到尾只有一条，新鲜感全来自配器。

## 3b. 两种发声引擎（v11，都可选）

`design/engine-ab.html` 的 "ab" 就是 **A/B 对照**：同一个调度器、同一份谱子、同一套场景参数，
只换发声实现，比的是**发声层**而不是功能多少。v11 把两路都接进来了。

| 引擎 | 实现 | 优点 | 代价 |
|---|---|---|---|
| **原生 Web Audio**（默认） | 手写加法钢琴（7 层泛音）、FM 电钢、Karplus 吉他、正弦+气声长笛、`addPartial` 系列 | 零依赖、起播零延迟、每个音色都能精调到想要的音色 | 代码量大，22 种音色得一个个手写 |
| **Tone.js 14.8.49** | `Tone.PolySynth` / `PluckSynth` / `MonoSynth` + `Tone.Reverb` / `Channel` | 一套参数就能出音色，混响/声道现成 | +349KB 库、需联网或本地文件；音色偏"通用"，没有手写那种精细 |

### 同接口设计

```
voice(kind, when, midi, vel, dur, bright, bus)
vPad(when, midi, dur, vel)
shaker(when, vel)
```

三个入口在 `engineMode === 'tone'` 时改为 `toneEnqueue(...)`，其余完全共用：
调度器、`THEMES`、`ACC_GRID`、`scene()`、`seed` 全部一致 ⇒ **产出的音符事件一模一样**。

### 三个必须知道的坑

1. **Tone 的时间轴必须单调**。`scheduleBar` 的真实写法不是时间单调的：
   先铺伴奏到 `t+3.5` 拍、再补左手和弦回到 `t`；装饰音还要往前挪 0.22 拍。
   裸 Web Audio 每个音各建一套节点，乱序无所谓；Tone 复用同一个 `PolySynth`，
   后一个音排到前一个之前会抛 `Start time must be strictly greater than previous start time`。
   **解法：整小节先收进队列，按时间排好再一次性下发**（`toneQueueOn` / `toneFlush`）。
   另外每个 rack 里还有 `if (t < lastT) t = lastT + 0.0005` 兜底。
2. **`Tone.start()` 可能永远不 resolve**（浏览器自动播放拦截时）。
   所有"等它恢复"的地方都必须带超时（`toneWait`），否则 `start()` 静默挂死。
   恢复后还要确认 `getContext().state === 'running'`，否则后面全排在一个不走的时钟上。
3. **音效仍走原生节点，但必须挂在 Tone 的上下文上**。
   `ctx` 在 Tone 模式下被设成 `Tone.getContext().rawContext`，
   所以 `sfxBus` / `noiseBuf` 要用**这个** ctx 创建，否则跨 context 连节点直接抛错。

### 库加载（三级回退）

`./tone.min.js`（同目录，离线可用）→ `cdn.jsdelivr.net/npm/tone@14.8.49` → `unpkg.com`。
都失败就**自动退回原生引擎**，把原因写在页面上 —— 对照台的意义是能听，不是能报错。

`docs/demo/tone.min.js` 是从 `engine-ab.html` 里抽出来的内联副本（349KB，MIT）。
如果不需要 Tone 对照，删掉这个文件、把 `ENGINES` 里 tone 那项去掉即可。

### 实测对比

| 引擎 | 状态 | 频谱重心 | <200Hz | >1.5kHz |
|---|---|---|---|---|
| 原生 | running | 2391 Hz | 5% | 54% |
| Tone.js | running | 575 Hz | 26% | 7% |

差异主要来自音源本身：原生钢琴是 7 层加法合成，Tone 侧是 `FMSynth(harmonicity:1, modulationIndex:1.8)`，
泛音少得多，加上 `Tone.Reverb` 2 秒全湿，听感明显更暗更远。
**这正是对照台要展示的东西** —— 不是 bug。

## 4. 刻意没搬的

| 项 | 原因 |
|---|---|
| Tone.js 后端 | 我们是零运行时依赖的 SPA，引一个 200KB 的音色库不划算；原生 Web Audio 的音色已经够 |
| 25 种音色全家桶 | 只搬了 5 种我们真用得上的（木吉他/电钢琴/长笛/马林巴/钢琴） |
| 随机变奏模式（每 4 小节换音型） | 变伴奏音型会让"记忆点"建立不起来，与 §3.0 的情绪目标冲突 |
| MIDI 导出 / 雨声床 / 8 个场景预设 | 本作是牌桌 BGM，用不到 |
| 参考曲的旋律 | **版权**。只借鉴结构手法 |
