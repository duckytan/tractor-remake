## 1. 移植清单

| # | 移植项 | 原文位置 | 为什么值得搬 |
|---|---|---|---|
| 1 | **钢琴 7 层泛音表** `PIANO_PARTIALS` | `engine-ab.html:672` | 我们原来只有 4 层，听感单薄发"电子"。7 层 + 每层独立衰减倍率，才有"高音先走、低音拖着"的真钢琴尾音 |
| 2 | **`playPiano` 的 `soft` 开关** | `:677` | `br<0.8` 时直接砍掉最高几层泛音 —— 同一个音色能出"亮/暗"两种性格，不用换音色 |
| 3 | **`phraseAccent()` 确定性力度呼吸** | `:418` | 我们原来用 `Math.random()`，听感是"散"。按「强拍重·弱拍轻·反拍再轻·句尾收·越高越亮」算出来才是"呼吸" |
| 4 | **`makeRng()` 确定性伪随机** | `:288` | 同一个小节每次生成的微抖动完全一致 ⇒ 可复现，不会越听越乱 |
| 5 | **分乐器总线 + 立体声定位** | `:568-594` | 吉他 −0.28 / 钢琴 +0.22 / 伴奏 −0.12 / 旋律 +0.06。分轨之后织体立刻"打开"，不再糊成一团 |
| 6 | **音色闸门 `tone`（8.5kHz 低通）** | `:555` | 一处低通干掉所有音色的高频毛刺，比在每个音色里各加一次省事 |
| 7 | **压缩器参数** | `:557` | `-20dB / knee 22 / ratio 2.6 / attack 12ms / release 280ms`，比我们原来的更松，不会"压扁" |
| 8 | **左手和弦层** | `:1921` | 根音 + 五音的长音铺厚度 —— 我们原来完全没有这一层，织体是"飘"的 |
| 9 | **和声床两个音** | `:1931` | `p[0]+12` 与 `p[2]` 各一个，比我们原来单音垫底宽 |
| 10 | **`dens` 当密度用** | `:1901` | `(dens-0.75)*0.34` 作为加花**概率**，不是当音量阈值用 |

| 15 | **旋律用绝对 MIDI 记谱** | `:314` | `[拍位, MIDI, 时值]`。能用导音、大七度这些五声里没有的颜色音 |

## 2. 主旋律（原创）

画面：「慵懒的下午，一群人在一起打牌」。8 小节 29 个音，音域 E4–E5。

写法上借鉴参考实现的**结构手法**（不是音符）：

| 手法 | 参考实现 | 我们的落地 |
|---|---|---|
| 有动机、隔小节再现 | spring 的 ①⑦ 节奏骨架逐拍相同 | 第 1、3 小节同一个「叹息」动机（下行级进 + 长音），第 3 小节整体移低 |
| 每小节节奏都不同 | autumn 八小节八种节奏 | 1/.5/1.5/.5 → 1/1.5/.5/1 → 2/2 → 1.5/.5/1/1 → … |
| 稳定句与色彩句交替 | 强拍落和弦音 | 第 2、4、6、8 小节全落和弦音；第 1、3、5、7 小节带 9 音/大七度/6 音 |
| 只有一次高点 | autumn 第 5 小节唯一 E5 | 第 5 小节 E5，全曲最高，只出现一次 |
| 沉到最低音 | autumn 第 7 小节 E4 | 第 7 小节 E4，叹气叹到底 |
| 半终止收尾、无缝循环 | autumn 停在导音 B4 | 第 8 小节停在 B4 两拍，接回第 1 小节 |

**和声校验**（纸面，`.tmp/` 下同）：29 个音里 20 个是和弦音、9 个色彩音，
**只有 1 处大七度**（第 5 小节 B4 对 C 和弦）—— 这是故意的留音，
下一小节立刻半音上行到 C5 解决，慵懒调子需要这个颜色。

**隔离实测**（清空伴奏网格后只留旋律，钩 `createOscillator` 记频率）：
出现的音级 `A×24 F×12 E×9 D×9 C×9 G×6`，**没有任何升降号**，控制台零错误。

## 3. 伴奏与编排

- **网格音型保留我们试听定稿的那一条**：低音在第 1 拍、第 2 拍后半、第 3 拍；
  五音+高三叠在第 2 / 4 拍。读作「咚 · 嗒 咚 咚 · 嗒」。
- **高三行整体再 +12**：马林巴是正弦泛音，八度一高，4×/9× 次泛音就落进
  3.5–5 kHz 的"空气"频段 —— 这是最便宜的补高频手段。
- **`bassMul`**：低音行按曲风单独缩放。慵懒要慢要松，低频太厚就变「沉」。
- **循环编排 8 小节一段 × 6 段 = 48 小节**：
  起 → 全奏 → 全奏 → 呼吸(抽旋律) → 转调+2 → 收尾。
  旋律从头到尾只有一条，新鲜感全来自配器。

## 4. 刻意没搬的

| 项 | 原因 |
|---|---|
| Tone.js 后端 | 我们是零运行时依赖的 SPA，引一个 200KB 的音色库不划算；原生 Web Audio 的音色已经够 |
| 25 种音色全家桶 | 只搬了 5 种我们真用得上的（木吉他/电钢琴/长笛/马林巴/钢琴） |
| 随机变奏模式（每 4 小节换音型） | 变伴奏音型会让"记忆点"建立不起来，与 §3.0 的情绪目标冲突 |
| MIDI 导出 / 雨声床 / 8 个场景预设 | 本作是牌桌 BGM，用不到 |
| 参考曲的旋律 | **版权**。只借鉴结构手法 |
