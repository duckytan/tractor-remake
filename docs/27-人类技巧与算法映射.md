# 27 · 人类技巧 → 算法规则映射

> 来源：百度百科（升级/甩牌规则）、微信公号「谁是高手」双升小技巧、百度文库《双升技巧十句口诀》、
> 知乎《四人升级规则说明》、百家号《双升术语及技巧》。
>
> 目的：把「人类高手怎么打」逐条落成**候选生成规则 / 评估特征 / 埋底规则**，
> 而不是停留在口号。标 ★ 的是**我们现在没做或做错**的。

## 1. 先复核两条规则（影响算法目标函数）

### 1.1 抠底倍数

| 末墩赢家的牌型 | 底牌分倍数 |
|---|---|
| 单张 | ×2 |
| 对子 | ×4 |
| 拖拉机（n 连对） | **2^(n+1)**（2 连对 = ×8，3 连对 = ×16） |

与我们逆向的结论一致（单 ×2 / 对 ×4 / 拖 ×8，升级 ≥80 时 80–119 只上台不升级）。

**算法含义**：埋底不只是「扣什么牌」，还要**预判末墩牌型** ——
如果对方很可能用拖拉机收尾，底牌留 10 分就是 ×8 = 80 分，直接翻盘。
这条我们现在完全没考虑。

### 1.2 甩牌失败罚则

> 「若首家试图联出的牌并非都是大牌时，则其必须出欲甩牌中**最小的牌**」

与我们逆向的「出失败组的最小单位」一致（单张 1 / 对子 1 对 / 拖拉机 4 张）。

**算法含义**：甩牌是有风险的进攻动作，候选生成时必须校验「每组都是全场最大」。

## 2. 埋底（扣底）—— 人类经验最密集的一块

| # | 人类技巧（原话/意译） | 落成规则 |
|---|---|---|
| B1 | **无分的花色必须下底，少分的花色尽量下底** | 优先扣「该门分牌数 = 0」的花色；其次扣分牌少的 |
| B2 | **把分拿在手里，比下底要踏实** | 底牌分越少越好 —— 直接作为埋底的目标函数（最小化 `cardsScore(buried)`） |
| B3 | 花色中多分而不能下底时，**尽可拆对牌下底** | 允许拆对子，但**只在必要时**（分牌保护优先于结构保护） |
| B4 | 打无主时，边家叫主花色 ≤5 张，可连 A 一起下底 | 无将局：对手叫过的花色若我 ≤5 张，整门扣光（防帮对手树套） |
| B5 | **不要重分埋底** | 硬约束：底牌总分超过阈值（如 20）就换方案 |
| B6 ★ | **扣底要看牌型，预判最后一轮** | 见 §6 收官 —— 我们现在没有 |

**这 6 条合起来就是新的埋底算法**（§7 给伪代码），核心思想：
**制造缺门 > 保护分牌 > 保护结构 > 扣低牌力**，且「底分最小」是硬指标。

## 3. 首出顺序 —— 同一门牌的最优打法

> 「应先出单张 A，再出对 A，然后是 AAK，最后出连对」

| # | 技巧 | 落成规则 |
|---|---|---|
| S1 | 同门顺序：**单张 → 对子 → 甩（对+单）→ 连对** | 清门候选按这个顺序生成，让评估函数去选 |
| S2 | 最大的牌先出（能保证最大就出，别赌） | 「兑现」意图：绝对大牌优先出 |
| S3 | **甩牌留牌多的那门，有大牌最佳** | 甩牌候选只在「该门有绝对大对」时生成 |

**注意 S1 的深意**：先出单张 A 再出对 A，是因为**单张 A 逼不出对手的对子**，
而对 A 会被对子压。所以「先小结构、后大结构」是防止被结构克制。

我们的候选生成目前完全不区分这个顺序 —— 补上之后，评估函数才有可能学到它。

## 4. 跟牌 / 压牌

| # | 技巧 | 落成规则 |
|---|---|---|
| F1 ★ | **一墩只比一次大小，队友最大 = 我方赢** ⇒ 队友领先时可以放心垫分牌 | `partnerLeading` 时**垫分牌要加分**（现在只是不扣分，没加分） |
| F2 | 对方都没主时不要再出主（等于叫队友的主） | 主牌使用前检查「对手是否还有主」 |
| F3 | 算主牌里的分牌，对方只剩分牌时继续用大主叫主 | 主牌压制时考虑「对手主牌里还有多少分」 |
| F4 | 缺门时明确判毙（原版系的 `WhoseOrderIs2`） | 候选生成增加「毙牌」意图 |

**F1 是我们现在的真实缺口**。看代码：

```ts
if (partnerLeading) {
  score += iAmWinning ? -0.5 : 0.4      // 只给了一个固定 +0.4
} else if (iAmWinning) {
  score += 0.6 + points * 0.08
} else {
  score -= points * 0.15                // 压不过时垫分牌扣分
}
```

队友领先时，垫一张 K（10 分）和垫一张 3 得分完全一样。
但人类知道：**队友赢 = 我方赢，垫的分还是我方的**，所以应该优先垫分牌。
这一条改起来只有一行，收益可能不小。

## 5. 团队配合

| # | 技巧 | 落成规则 |
|---|---|---|
| T1 | **送上手**：故意出牌让对家获得出牌权 | 「递牌」意图（原版系已有，我们没有） |
| T2 | 拆拖：把拖拉机拆成对子打（有时拆更优） | 候选生成要包含「拆结构」的变体 |
| T3 | 牌语（正规比赛禁用） | **不做** —— AI 只能靠出牌逻辑推断，不能假设约定信号 |

T3 这条要记牢：**不能给 AI 加"人类暗号"**，否则打起来像作弊。
但可以加「从对手的出牌序列推断其手牌结构」（这是合法的推理）。

## 6. 收官与抠底 ★

| # | 技巧 | 落成规则 |
|---|---|---|
| E1 | **7 拆 8 不拆**：剩 8 张时对手有两次抠底机会，7 张是安全阈值 | 收官阶段（手牌 ≤ 8）拆牌型优先于保结构 |
| E2 | 保留组合牌型（对子/拖拉机）用于最后 | 收官阶段「结构完整」权重上调 |
| E3 | 赢末墩时尽量用**拖拉机/对子**（倍数高） | 末墩候选生成时，对子/拖拉机额外加分 |
| E4 | 庄家埋底要预判末墩牌型 | 埋底时若对手主牌多，倾向少留分 |

**E3 是一个很有意思的战术**：明明用单张就能赢末墩，但用对子能拿 ×4、用拖拉机 ×8。
前提是「用对子/拖拉机也能赢」—— 这需要精确判断对手末墩的牌型。

## 7. 新埋底算法（把 §2 的规则落成伪代码）

```
埋底(hand, ctx, 对手信息):
  1. 统计四门副牌：张数、分牌数、是否有绝对大牌
  2. 候选目标缺门 = 按「(分牌数, 张数) 升序」排序的第一门
     —— 无分优先，其次张数少（更容易扣绝）
  3. 从目标门扣牌（按牌力从低到高），直到扣够 8 张
  4. 目标门不够 8 张时，继续从其他门扣，但：
     a. 优先非分牌
     b. 不拆完整拖拉机（拆了就是废牌）
     c. 不扣绝对大牌（留着毙牌/兑现）
  5. 硬约束：底牌总分 > 20 时，回退到「扣分牌最少的 8 张」方案
  6. 无将局特例：对手叫过的花色若我 ≤5 张，整门扣光
  7. 收官预判：若对手主牌多且我方无强末墩，优先扣光分牌
```

**可验证指标**：底分（`cardsScore(buried)`）应显著低于现在。
现在按牌力扣最弱 8 张，很容易把 5/10/K 扣进去；新算法下底分应该接近 0。

## 8. 记牌与算牌

人类记牌是为了**推断**，我们的 AI 有完美信息，所以「记牌」这一步不需要。
但**「推断对手意图」需要** —— 这正是 docs/26 §3 概率化对手模型的输入：

| 人类推断 | 我们的实现 |
|---|---|
| 对手连续出主花色 → 主牌储备减少或持有强主组合 | 从已出牌统计各家主牌消耗速度 |
| 对手迟迟不毙 → 缺门或主牌少 | 用「他这轮没出主」反推主牌数 |
| 对手垫分牌 → 他在求过牌（赢不了这墩） | 从垫牌行为反推他手上没大牌 |

**这些都是合法推理**（只用已出信息），不依赖完美信息 ——
为将来改成「不完全信息」留了口子。

## 10. 立即可做的一条

**F1（队友领先时垫分牌要加分）** —— 改动一行，可以立刻跑标定看收益：

```ts
if (partnerLeading) {
  // 队友赢 = 我方赢，垫的分还是我方的 ⇒ 垫分牌是好事
  score += iAmWinning ? -0.5 : 0.4 + points * 0.1
}
```

这是所有技巧里**投入产出比最高的一条**：一行代码、一条断言、一次标定。
